iOS (SF Pro - use system San Francisco):
- Do NOT bundle SF Pro (Apple proprietary). The app uses the system San Francisco font on iOS automatically via Theme.
- If you have a licensed SF Pro for internal testing, place:
  assets/fonts/ios/SFProText-Regular.ttf
  assets/fonts/ios/SFProText-Medium.ttf
  assets/fonts/ios/SFProText-Semibold.ttf
  assets/fonts/ios/SFProText-Bold.ttf
